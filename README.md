# chiragkapoor1711-student_managment_system
## 📌 Features

- 🔐 **Login Authentication**
- 🧑‍🎓 **Add, Update, Delete Student Details**
- 🔍 **Search Students by Name or ID**
- 📋 **View Complete Student List**
- 📁 **Export Data to Excel**
- 🗄️ **SQL Database Connectivity**
- ✅ **User-friendly GUI using Tkinter**

## 🛠️ Technologies Used

- **Python 3.x**
- **Tkinter** (for GUI)
- **SQLite3 / MySQL** (for database)
- **Pandas** (for Excel export)
- **OpenPyXL** (for Excel handling, optional)
